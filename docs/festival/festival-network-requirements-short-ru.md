# Короткие требования к сети для фестивального запуска

Документ для организатора площадки. Цель: обеспечить стабильную работу QR-заказа и выдачи в часы, когда придет больше всего людей.

## 1) Обязательные вводные от площадки

- Какие есть условия по Wi‑Fi (какое покрытие, чья это сеть, есть ли ограничения)?
- Какой прогноз по количеству гостей и в какие часы ожидается пиковая толпа?

## 2) Минимальные условия сети

1. **Разделение сетей (это критично)**
   - отдельная сеть для работы (персонал, кассы, планшеты поваров);
   - отдельная гостевая сеть для посетителей;
   - как минимум это должны быть сети с разными названиями, в идеале — полное программное разделение, чтобы гости своими телефонами не мешали работать поварам.

2. **Гостевая сеть**
   - быстрый вход без долгих регистраций и СМС;
   - ограничение на скачивание тяжелых файлов для каждого человека;
   - контроль максимального количества подключенных телефонов.

3. **Рабочая (операционная) сеть**
   - настройка приоритета для заказов (система должна пропускать чеки и статусы в первую очередь);
   - нельзя использовать гостевой Wi‑Fi как единственный интернет для планшетов на кухне.

## 3) Wi-Fi сеть из нескольких вышек (Mesh-сеть)
*(нужно, если площадка большая или сложной формы)*

- минимум 1 главная станция + дополнительные точки раздачи Wi-Fi по всем зонам;
- надежная связь между этими точками (лучше всего соединить их кабелем, а не "по воздуху");
- ровное покрытие интернетом без "слепых зон" на фудкорте и в зоне выдачи;
- оборудование должно выдерживать максимальное ожидаемое количество гостей в один момент + запас 30-50% прочности.

## 4) Лимиты подключений (нужно договориться заранее)

- максимальное число людей, которое может "висеть" на одной Wi-Fi точке;
- общий лимит подключений на всю гостевую сеть;
- ограничение скорости для одного гостя (чтобы кто-то один не начал смотреть видео и не "положил" всю сеть для остальных).

## 5) Что будет, если сеть не выдержит (основные риски)

- заказы на кухню будут приходить с задержками или теряться;
- гостевая сеть просто "ляжет" в самый пик фестиваля;
- люди не смогут открыть меню по QR-коду и начнут возмущаться;
- возникнут конфликты, так как телефоны гостей забьют рабочий интернет поваров.
