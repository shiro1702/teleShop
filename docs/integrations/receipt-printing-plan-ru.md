# План интеграции печати чеков (Бегунки для кухни)

## 1. Контекст и проблематика
На фестивалях и у небольших стритфуд-корнеров (где нет полноценных касс вроде iiko/QuickResto) часто используется зоопарк из дешевых китайских Bluetooth/USB термопринтеров. 
Наше веб-приложение (TeleShop Dashboard) работает в браузере. Напрямую из браузера отправить команду на Bluetooth-принтер без сложных диалоговых окон затруднительно.

**Цель:** Дать возможность автономным точкам быстро и стабильно печатать чеки (встречки на кухню) с планшетов и телефонов при поступлении новых заказов через TeleShop.

## 2. Архитектурное решение

Мы будем использовать гибридный подход, закрывающий 100% кейсов:

### Основной метод (Для Android + Любой термопринтер)
**Использование приложения RawBT.**
RawBT — это универсальный бесплатный драйвер печати для Android, который умеет перехватывать специальные ссылки из браузера (`intent://`) и мгновенно отправлять текст на подключенный принтер по Bluetooth, USB или Wi-Fi.
* **Плюсы:** Мгновенная печать без всплывающих окон браузера. Поддержка 99% китайских термопринтеров. Форматирование текста (жирный, центрирование, размер) через простые теги.
* **Минусы:** Работает только на ОС Android.

### Резервный метод (Для ПК, Ноутбуков, iPad)
**Системная печать (HTML + `window.print()`).**
Генерация скрытого HTML-шаблона шириной 58мм/80мм и вызов системного диалога печати браузера.
* **Плюсы:** Работает везде, где принтер определяется как системное устройство (Windows, macOS, iOS через AirPrint).
* **Минусы:** На планшетах требует лишнего клика "Подтвердить печать" в интерфейсе ОС.

### Альтернатива (Для iOS / без принтеров)
Apple (iOS/iPadOS) жестко блокирует работу с дешевыми Bluetooth-принтерами (без сертификации MFi). 
* **Решение:** Если у точки только iPad/iPhone, мы рекомендуем использовать наш цифровой **Экран повара (KDS)** без бумажных чеков, либо приобрести дешевый Android-смартфон (от 3 тыс. руб) исключительно как станцию печати.

## 3. План реализации (Frontend-first)

Поскольку вся логика формирования чека и вызова печати лежит на клиенте, бэкенд практически не затрагивается.

### Шаг 1: Утилита форматирования чека (`utils/receiptPrinter.ts`)
Создать универсальный сервис, который принимает объект заказа (`KitchenOrder`) и возвращает готовые команды для печати.

**Функции сервиса:**
- `generateRawBTUrl(order)`: Формирует строку с тегами RawBT и оборачивает её в `intent://...`.
  *Пример тегов RawBT:* 
  ```text
  [C]<b>Заказ #1234</b>
  [L]Доставка: 18:30
  [C]--------------------------------
  [L]Бургер классический [R]x2
  [L]<small>Модификаторы: Без лука</small>
  [C]--------------------------------
  [C]Спасибо за заказ!
  ```
- `generateHtmlReceipt(order)`: Генерирует HTML-строку со стилями под термоленту (ширина ~200px) для вызова в скрытом iframe (`window.print()`).

### Шаг 2: Настройки филиала
Добавить в настройки филиала (или локальные настройки устройства (Local Storage)):
- Способ печати: `RawBT (Android)` | `Системный диалог` | `Отключено`.
- Ширина ленты: `58 мм` | `80 мм`.

### Шаг 3: Интерфейс KDS (`pages/dashboard/branches/[id]/kitchen.vue`)
1. В карточку каждого заказа (и в модальное окно заказа) добавить кнопку-иконку **«🖨 Печать»**.
2. **Автопечать (опционально):** Добавить чекбокс «Автоматически печатать новые заказы». Если включен, при попадании нового заказа в колонку `new` по вебсокету (или при поллинге), сразу триггерить печать. (Для RawBT это будет невидимый переход по `intent://` ссылке).

## 4. Требования к железу (Памятка для организаторов/корнеров)
Чтобы всё работало как швейцарские часы:
1. **Устройство:** Смартфон или планшет на базе **Android 8.0 и выше**.
2. **Принтер:** Любой Bluetooth ESC/POS термопринтер (обычно ширина ленты 58мм, стоимость от 1500 до 3000 руб).
3. **Софт:** Скачанное приложение `RawBT print service` из Google Play.
