# Лендинг партнеров — вариант 3 (конверсионный: максимум заявок)

## Для чего этот вариант
Подходит для рекламы и холодного трафика: быстро объяснить "что это", показать выгоду и сразу забрать лид.

## Логика блоков (сверху вниз)

### 1) Hero + форма на первом экране
- Заголовок: `Запустите не просто сайт, а экосистему заказов для доставки еды`
- Подзаголовок: `Сайт + QR-меню + mini app в мессенджерах + горячие лиды из общего канала`
- Форма: имя, телефон/Telegram, тип заведения, город.
- CTA: `Получить демо и расчет по модулям`

### 2) Быстрый блок "Что вы реально покупаете"
- Не шаблон и не "разовая разработка".
- Платформа, которая растет вместе с рестораном.
- Подключение нужного функционала по модулям, а не по жестким тарифам.

### 3) 4 выгоды за 10 секунд чтения
- `Горячие лиды` — поток заказов из общего канала агрегатора.
- `Удобство гостю` — привычный заказ в сайте/QR/мессенджере.
- `Рост повторов` — рассылки, бонусы, промокоды, сторис-механики.
- `Контроль бизнеса` — единая база клиентов и заказов.

### 4) Отдельный блок: таблица цен по модулям
| Модуль | Что подключается | Цена |
|---|---|---|
| `core_qr_menu` | QR-меню | 0 ₽ |
| `core_telegram_orders` | Telegram-заказы/уведомления | 0 ₽ |
| `crm_orders_db` | База гостей + история + повтор заказа | 1000–1500 ₽/мес |
| `marketing_loyalty` | Бонусная система + промокоды + штампики | 500–990 ₽/мес |
| `payments_online` | Онлайн-оплата | от 480 ₽/мес |
| `ugc_reviews` | Сбор, модерация и публикация отзывов гостей | от 700 ₽/мес |
| `own_delivery_smart` | Своя доставка (геозоны, филиалы, меню по режимам) | 2000–3500 ₽/мес |
| `traffic_boost_search` | Поднятие в поиске агрегатора | В планах — после запуска страницы агрегатора |
| `traffic_promo_showcase` | Витрина акций на главной | В планах — после запуска страницы агрегатора |

> Механика продаж: ресторан начинает с ядра и подключает только те модули, которые дают понятную окупаемость.

### 5) Блок "Омниканальность в одном контуре"
- Сайт под брендом ресторана.
- Миниаппы в мессенджерах для быстрых заказов.
- QR-меню в офлайне.
- Общая логика корзины, заказа и промо.

### 6) Блок "Экосистема партнеров и кросс-продажи"
- Кросс-партнерка между ресторанами, кафе, барами, киосками.
- Совместные акции и обмен трафиком внутри платформы.
- Дополнительный инструмент роста без классической "дорогой" рекламы.

### 7) Блок "Маркетинговый конвейер"
- Рассылки в мессенджерах по сегментам.
- Автоматические триггеры (дни рождения, реактивация, гео).
- Бонусы и промокоды.
- Сторис-формат для акций, новинок и повышения конверсии.

### 8) Мини-калькулятор выгоды
- Поля: формат работы (доставка/самовывоз/зал), количество филиалов, подключаемые модули.
- Тарифная логика: база `1200 ₽/мес`, каждый дополнительный филиал `+500 ₽/мес`.
- Вывод: итоговая стоимость по формуле `база + форматы + филиалы + модули`.
- CTA: `Получить персональный сценарий роста`.

### 9) Снятие возражений
- "У нас уже есть сайт" -> расширяем до экосистемы с заказами и retention.
- "Мы не хотим сложную внедренку" -> запуск поэтапно: ядро, потом модули.
- "Боимся переплатить" -> оплачиваются только активные модули.
- "Нужны лиды, а не отчеты" -> есть общий канал трафика и промо-модули.

### 10) Финальный CTA
- Заголовок: `Соберем вам топовый ресторанный сайт-платформу по подписке`
- Подзаголовок: `От QR-меню до омниканальной экосистемы продаж`
- Кнопки:
  - `Оставить заявку`
  - `Написать в Telegram`

## Почему этот вариант работает
- Максимально быстро доносит ключевой оффер и отличия от "обычной разработки сайта".
- Упирает в лидогенерацию, удобство клиента и рост LTV.
- Отлично подходит для A/B тестов рекламных креативов.
