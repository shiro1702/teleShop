# TODO: Режимы маршрутизации чатов для доставки и самовывоза

## Идея

- Для `delivery` использовать отдельный чат с менеджером (централизованный поток).
- Для `pickup` маршрутизировать заказы по чатам филиалов.
- Режимы должны переключаться в настройках дашборда.

## Зачем

- Менеджеры видят общую картину загрузки филиалов.
- Можно оперативно перераспределять заказы между филиалами.
- Уменьшается риск перегруза одного филиала при неравномерной нагрузке.
