# Рилс 05 — Умная доставка: подсказки адреса, зоны и пеший курьер по району

**Номер публикации:** 05  
**Рабочее название:** Не поле «введите адрес», а подсказки и проверка зоны  
**Аудитория:** кто запускает или масштабирует доставку

## Задача ролика

Показать сайджест адреса, попадание в зону, гибкие тарифы по зонам, лайфхак старта без машины.

## Видеоряд

Экран ввода адреса, карта зон (если есть в демо).

## Сценарий (текст)

Думать, что доставка — это одно поле «введите адрес», наивно. Люди ошибаются в улицах. В платформе умный поиск: подсказки, нормализация, проверка — попадает ли дом в зону.

Зоны настраиваются гибко: рядом бесплатно, дальше платно. Лайфхак для бизнеса: нет машины и курьера — сделайте зону в радиусе квартала, термосумка и пеший разнос. Так можно проверить гипотезу доставки без больших рисков. Нужен такой умный контур — пишите.

## Про продукт

Модуль `own_delivery_smart`: зоны, гео-резолвинг, ограничения меню по режиму (см. `docs/content/brainstorm/тариф.md`).
